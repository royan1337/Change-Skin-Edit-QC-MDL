Batasan jujur: ini mengedit langsung field numerik yang sudah ada di struktur biner mstudioseqdesc_t (fps, flags/loop, activity, actweight) — ukuran file tidak berubah sama sekali, jadi aman dan tidak butuh recompile. Nama sequence (label) juga bisa diubah selama panjangnya ≤ 31 karakter. Yang tidak bisa dilakukan tanpa decompile+compile penuh (studiomdl/Crowbar): menambah frame animasi baru, mengubah pose/tulang, atau menambah sequence baru — itu butuh data animasi terkompresi yang harus di-generate ulang oleh compiler asli.

Soal pratinjau mesh: tangan, senjata, dan teksturnya di panel "Preview Animasi" direkonstruksi langsung dari mesh + tekstur yang ada di .mdl-nya sendiri (bukan model generik) — bentuknya mengikuti submodel/bodypart pertama dan skin family default. Batasannya: kalau model punya beberapa varian bodygroup (mis. skin tangan berbeda), yang ditampilkan cuma varian pertama; efek chrome/reflection tidak disimulasikan (jadi bagian metal mengkilap bisa terlihat datar); dan render pakai depth-sorting sederhana tanpa backface culling, jadi geometri yang sangat tumpang tindih bisa sesekali salah urutan gambar. Kalau sequence-nya data animasinya ada di file seqgroup eksternal (bukan di .mdl utama), preview otomatis balik ke mode skeleton titik karena data itu di luar jangkauan file ini.

Efek kilatan tembak: tombol "🔫 Tes Tembak" loncat ke sequence shoot/fire berikutnya lalu memutarnya; kilatannya otomatis muncul persis di frame event tembak asli model (event 5001) dan menempel di titik moncong senjata (attachment pertama), bukan cuma efek generik di tengah layar — kalau sequence-nya tak punya event itu, dianggap tembak di frame 0 (asumsi umum). Matikan lewat centang "efek kilatan tembak otomatis" kalau tak perlu. Tekstur juga sekarang cuma di-decode saat benar-benar dipakai (bukan semua varian sekaligus), supaya file besar tetap ringan dibuka di HP.
